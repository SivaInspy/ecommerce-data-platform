# Power BI Dashboard

This directory contains the Power BI reporting assets for the Real-Time E-Commerce Data Platform.

## Data Source

The dashboard consumes analytical datasets generated by the Spark Gold layer:

- Revenue by Category
- Revenue by City
- Overall Metrics
- Sales Trend

## Architecture

Kafka → Spark → Bronze → Silver → Gold → Power BI

## Dashboard

The dashboard provides:

- Total Orders
- Total Revenue
- Average Order Value
- Revenue by Category
- Revenue by City
- Sales Trend

The Gold layer is used as the reporting source to ensure that Power BI consumes validated analytical data rather than raw or intermediate datasets.
