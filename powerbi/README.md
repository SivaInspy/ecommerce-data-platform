# Power BI Dashboard

This directory contains the Power BI reporting assets for the Real-Time E-Commerce Data Platform.

## Data Source

The dashboard consumes analytical datasets generated by the Spark Gold layer:

- Revenue by Category
- Revenue by City
- Overall Metrics
- Sales Trend

## Architecture

Kafka → Spark → Bronze → Silver → Gold → Power BI

## Dashboard

The dashboard provides:

- Total Orders
- Total Revenue
- Average Order Value
- Revenue by Category
- Revenue by City
- Sales Trend

The Gold layer is used as the reporting source to ensure that Power BI consumes validated analytical data rather than raw or intermediate datasets.

# Power BI report

This directory contains `ecommerce-data-platform.pbix` and `Dashboard.png`. The report presents overall order/revenue KPIs, category and city revenue, and a daily sales trend.

The reporting datasets are generated by Spark from Gold Parquet and exported as CSV files in `spark/bi_export/`: `overall_metrics.csv`, `revenue_by_category.csv`, `revenue_by_city.csv`, and `sales_trend.csv`. Regenerate them from the current Gold output with `python export_gold_to_csv.py` from `spark/` before refreshing the report. If the PBIX data source points to another machine's path, use Power BI's data source settings to select the local export files and refresh.

CSV files are a reporting interchange format; rebuild them from Gold rather than making manual edits. See the [root README](../README.md) for the full pipeline and [BI export notes](../spark/bi_export/README.md).
